QUICK SNIP — BRAVE / CHROME UNPACKED EXTENSION

INSTALL
1. Extract this ZIP to a permanent folder.
2. Open brave://extensions (Chrome: chrome://extensions).
3. Turn on Developer mode.
4. Click Load unpacked and select the quick-snip folder containing manifest.json.

USE
Press Ctrl+Shift+S, drag a rectangle, and release the mouse.
The selected area is copied as a PNG image. Paste with Ctrl+V.
Esc or right-click cancels. Clicking the extension toolbar icon also starts capture.
On macOS the default shortcut is Command+Shift+S.

CHANGE HOTKEY
Open brave://extensions/shortcuts and set Quick Snip's shortcut.
If the default key is already assigned, assign a different key there.

NOTES
Captures the currently visible portion of the webpage, at screenshot resolution.
The page image freezes when capture starts; scroll to the desired area first.
Browser settings, new-tab pages, extension stores, and some built-in viewers
cannot be captured with this extension. Open a normal webpage instead.
For file:// pages, enable Allow access to file URLs in the extension's Details.
For private windows, enable Allow in Private in Details.
If clipboard access is blocked, a Copy again button lets you retry explicitly.

PRIVACY
No servers, analytics, uploads, libraries, or saved screenshot history.
Images remain in memory until copied/cancelled or the temporary capture expires.
activeTab and scripting allow capture and the selection overlay only when invoked.
clipboardWrite allows copying the PNG. No clipboard reading permission is requested.

Keep the extracted folder in place while the extension is installed.
